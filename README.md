# Muse

A minimal, intentionally dull SwiftUI iPhone app demo for an AI assistant named Muse.

## What it includes
- Simple chat UI
- Muted gray design
- Basic input and assistant reply flow
- Mock AI service that responds without an API key

## How to use
1. Open this folder in Xcode.
2. Create or select an iPhone simulator.
3. Run the app.
4. Type a prompt and tap Send.

## App structure
- `MuseApp.swift` – app entry point
- `Models/Message.swift` – chat message model
- `Services/AIService.swift` – simple response generator
- `Views/ContentView.swift` – main SwiftUI screen

## Notes
This is a starter app designed to be plain and calm rather than flashy or overstylized.

```markdown
# muse-ai-ios
Muse - AI Agent iOS App
```

This project is intentionally minimal and suitable as a starting point for a more advanced Muse assistant.
